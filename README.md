# エハブミカオス（音ゲー連動ゲーム）

左半分が音ゲー、右半分が「10秒遅れで始まる別ゲーム」。2つのゲームが互いに影響し合います。
右のゲームは **シューティング / ブロック崩し / 格闘ゲーム / ブラックジャック / 恋愛シミュレーション / おみくじ** の6種類で、40秒ごとにランダムで切り替わります（すべて矢印キーだけで操作）。
おみくじだけは1プレイに1度しか出ず、結果を見せたらすぐ次のゲームに移ります。

| 方向 | 起きること |
|---|---|
| 右 → 左 | シューティングで**撃ち漏らした敵**が、左の音ゲーの**特典ブロック**を壊す |
| 左 → 右 | 音ゲーの**10コンボごと**と、**GREAT以上の判定10回ごと**（コンボが切れても累計）に、右のゲームに**パワーアップアイテム**が届く |
| 右 → 左 | シューティングで**敵を10体倒すごと**に、壊れた特典ブロックが**ランダムに1個回復**する |

## 遊び方

1. **`start.bat` をダブルクリック**（ブラウザでゲームが開きます。黒い窓を閉じると終了）
   - `index.html` を直接開いても動きますが、その場合は収録曲が読み込めません（ブラウザの制限）。
     「ほかの音楽ファイル」から手元のファイルを選ぶ遊び方だけになります。
2. 曲の横の **EASY / NORMAL / HARD** を押す（初回は解析に数秒かかります）
3. 「スタート」または **Enter**

| 操作 | キー |
|---|---|
| 音ゲー（4レーン） | `A` `S` `D` `F` |
| 右のゲーム | 矢印キーのみ（下の表） |
| 一時停止 / 再開 | `Esc` |

### 右のゲーム

| ゲーム | 操作 | 左に悪いこと | 左に良いこと | 左からの報酬で出るもの |
|---|---|---|---|---|
| シューティング | 矢印で移動（自動で撃つ） | 敵を撃ち漏らす → 1個壊れる（大型は2個） | 10体撃破 → 1個回復 | 連射 / 拡散 / シールド / ボム |
| ブロック崩し | ← → パドル | ボールを落とす・列が赤線まで下りる → 1個壊れる | ブロック10個破壊 → 1個回復 | ワイド / マルチボール / スロー / ボム（一番下の列を消す）。さらに音ゲーで GREAT 以上が出るたびに貫通力+1（最大5）、MISS で−1 |
| 格闘ゲーム | ← → 移動 / ↑ ジャンプ / ↓ 攻撃 / 相手と逆を押すとガード / 相手の方向＋↓でガードの上から当たる攻撃 | 被弾 → 1個壊れる（体力0で2個） | KO → 2個回復 | パワー / 回復 / アーマー / 必殺技 |
| ブラックジャック | ← → 賭け数 / ↑ ヒット / ↓ スタンド | 負け → 賭けた数（1〜3個）壊れる | 勝ち → 賭けた数だけ回復（ブラックジャックは+1） | のぞき見 / バースト保険 / ダブル / ラッキー |
| 恋愛シミュレーション | ↑ ← → ↓ で4択を選ぶ | BAD END → 1個壊れる | TRUE END → 2個回復 / GOOD END → 1個回復 | ヒント / チャーム / プレゼント / 運命 |
| おみくじ（1プレイに1度） | ↑ ← → ↓ で箱を選ぶ | 凶 → 1個 / 大凶 → 2個壊れる | 大吉 → 3個 / 中吉 → 2個 / 小吉・吉 → 1個回復（末吉は影響なし） | なし（結果だけで決まる） |

- どのゲームも曲と連動します：シューティングは敵の出現、ブロック崩しは上から列が押し込むタイミング、
  格闘は敵の攻撃（「!」の後に来る。相手と逆を押してガードするか、↑ジャンプでかわす。「!」の間に攻撃を当てるとカウンター）、
  ブラックジャックはディーラーがカードをめくるタイミングが、10秒前に流れた曲の強い音に合わせてあります。
- ブロック崩し：上から列が押し込んでくる間隔は最低3秒。貫通力の数だけ、ボールがブロックを跳ね返らずに突き抜ける
  （パドルで打ち返すと貫通の残りが元に戻る。ボールは貫通が残っているほど赤く光る）。
- 格闘ゲームの敵もガードする。普通の攻撃（↓だけ）は防がれるので、相手の方向を押しながら↓の「踏み込み攻撃」で崩す
  （ガードの上からダメージ＋ガードを解く。代わりに次の攻撃まで少し長い）。
- 恋愛シミュレーション：キャラ（ひなた・しずく・ミコト）が質問し、4択で好感度が上下。3問答えるとエンディング
  （好感度95以上 TRUE / 75以上 GOOD / 45以上 NORMAL / それ未満 BAD）。答えの矢印の位置は毎回入れ替わり、10秒答えないと「無視」で下がる。
  エンディングの後は次のキャラとのデートが始まる。質問や答えは [js/side/games/romance.js](js/side/games/romance.js) の `CHARACTERS` で増やせる。
- おみくじ：結果（大吉・中吉・小吉・吉・末吉・凶・大凶）、ラッキーカラー、ラッキーナンバー（1〜99）、
  一言「〜上手く行く可能性がある」（「とりあえず」「かなり」「無理かもしれないが」など15種類からランダム）を表示。
  10秒選ばないと勝手に引かれる。出やすさや一言の種類は [js/side/games/omikuji.js](js/side/games/omikuji.js) で変えられる。
- 報酬の4つ目（ボム・必殺技・ラッキーなど）は、5回目ごとのコンボ報酬で出ます。
- 結果画面には、遊んだゲームごとの成績がまとめて出ます。切り替えの間隔は `config.js` の `sideGameRotateInterval`（0で切り替えなし）。

### ルールの細部
- **特典ブロック**：各レーンの判定ライン下に3個ずつ。残っている数だけ、そのレーンの得点が増える（3個で x1.75）。
- 敵が画面下に逃げた**横位置**で、どのレーンのブロックが狙われるかが決まる（右画面の下端を4分割）。大型敵は2個壊す。
- 全部壊れた状態で攻撃を受けると減点。25コンボごとに1個修復。
- シューティングの10体撃破ごとの回復は、緑の光が飛んできて壊れたブロックのどれか1個を直す（壊れたブロックが無ければ +500点）。
  右画面の左上に「回復まであと何体」が出る。
- 右の敵は「**10秒前に流れた曲の強い音**」に合わせて出てくる（だから10秒遅れで始まる）。
- アイテム：R=連射 / S=拡散（最大2段階） / G=シールド / B=ボム（50コンボごと）。GREAT以上の累計報酬は R/S/G のどれか。

数値はすべて [js/config.js](js/config.js) で調整できます。

曲選択画面では、タイトルの下に歌詞の言語（日本語・英語・韓国語・中国語）が表示されます（`songs.js` の `lang`）。

曲選択画面の「並び順」で、EASY / NORMAL / HARD のどのレベル順に並べるかを選べます（同じレベルなら他の難易度のレベル、BPM の順）。

- **EASY**：4分音符（拍の頭）だけ。1秒に1.1〜1.5個
- **NORMAL**：8分音符まで（シャッフルの曲は3連符）、たまに同時押し。1秒に1.9〜2.9個
- **HARD**：16分音符まで（速い曲は8分、シャッフルの曲は3連符）、同時押しが多め。1秒に3.2〜4.7個
- 1秒あたりの数は曲のテンポに合わせて調整（速い曲ほど少し多い）
- ノーツの流れる速さも難易度で変わる：EASY はゆっくり（1.7秒で判定ラインへ）、NORMAL は1.4秒、HARD は速め（1.15秒）。
  `config.js` の `approachTimes` で調整できます。

曲ごとの設定は [songs/songs.js](songs/songs.js)。曲を足すときは mp3 を `songs/` に置き、ここに1項目追加します
（`level` を省くと密度から自動で付きます）。

自己ベストはブラウザに保存され、曲選択画面に表示されます。

## 結果の共有
終了画面に結果画像（1200×675 の jpg。曲のジャケット・ランク・スコア・右のゲームの成績入り）が出て、次のボタンで共有できます。
ハッシュタグは `#完全空気エハブミさん #エハブミカオス`（[js/config.js](js/config.js) の `share.hashtags`）。

| ボタン | 動き |
|---|---|
| 画像を保存 | 結果画像を jpg でダウンロード |
| X に投稿 | X の投稿画面を文章・ハッシュタグ・ゲームのURL入りで開く。画像はクリップボードにコピーされるので、投稿欄で Ctrl+V で貼る |
| LINE で送る | LINE の送信画面を文章入りで開く（LINE のリンクでは画像は送れない） |
| Instagram | スマホ：共有メニューに画像を渡す（Instagram を選べる）／ PC：画像を保存して Instagram を開く（投稿画面を開くリンクが無いため） |

ゲームのURLは `config.js` の `share.url` に書くと、投稿文と結果画像に入ります。

## 歌詞の表示
収録曲は、歌詞全体が音ゲーの背景（ノーツの後ろ）を流れます。判定ラインの下から出てきて、奥の遠くへ小さくなりながら消えていきます（映画のオープニングのような遠近法）。
各行は歌い出しの瞬間に判定ラインの少し上を通ります（色は変わらず、ただ流れるだけ）。
流れ方（文字の大きさ・消える高さ・速さなど）は [js/rhythm/rhythmGame.js](js/rhythm/rhythmGame.js) の `LYRIC` で調整できます。
曲選択画面の「歌詞を背景に表示する」で消せます。

- 歌詞の文字は mp3 に埋め込まれている歌詞（SUNO が入れたもの）を使用。
- タイミングは、Stems.zip のボーカルだけの音（Lead Vocal）から「歌っている所・息継ぎ」を調べ、
  各行の文字数に見合う長さの区間へ自動で割り当てたもの（作成ツールは手元にのみあり、公開していません）。
  自動なので、1行ほど早い・遅い所があり得ます。
- 直し方：
  - タイミングだけ直す → `songs/lyrics/<曲ID>.json` の `t`（歌い出し秒）/ `e`（歌い終わり秒）を書き換える
  - 歌詞の文字を差し替える → 手元の作成ツールで作り直す
    （実際に歌っている通りに、繰り返しも含めて書くとタイミングが合いやすい）

## 譜面について
曲は読み込み時に自動で解析して譜面にします（[js/rhythm/chartGenerator.js](js/rhythm/chartGenerator.js)）。
- 音が急に増えた瞬間（オンセット）をノーツ候補にする → **リズム**
- 曲の拍を追跡し（テンポが少し揺れる曲にも追従）、候補を4分/8分/16分音符の位置にそろえる
- その瞬間の音の高さで、低い音ほど左、高い音ほど右のレーンに置く → **メロディ**の上下に近い動き
- 静かなイントロなどで4秒以上ノーツが途切れる所は、その区間の目立つ音で補う

タイミングがずれて感じる場合は `config.js` の `audioOffset` を調整してください。

## フォルダ構成
```
start.bat               起動用（tools/serve.py のローカルサーバー＋ブラウザ。更新したファイルがすぐ反映される）
index.html              画面の骨組み
songs/                  収録曲（mp3）と曲ごとの難易度設定 songs.js、歌詞タイミング lyrics/
css/style.css
js/config.js            調整値（まずここ）
js/main.js              起動・画面遷移・ループ・左右のつなぎ込み
js/core/                イベントバス・入力・音声
js/rhythm/              譜面自動生成・音ゲー本体
js/side/sideGame.js     右側ゲームの共通の形と登録簿
js/side/sideGameManager.js  10秒遅れの開始・ランダム選択・切替
js/side/games/          右側のゲーム（shooter / breakout / fighter / blackjack / romance / omikuji、ひな形 _template.js）
docs/DESIGN.md          設計メモと今後の予定
```

ビルドもインストールも不要です（素の HTML + JavaScript）。
